## 1. 项目概述

网页版城市/基地建设经营游戏。核心:**养活自己世界的人民**,从部落时代(I)发展到世界帝国(X),共 10 个文明时代。

- 先网页 + PWA,后期 Capacitor 打包上架 Google Play / App Store
- 账号 + 服务器存档;互动:排行榜、参观好友城市(无玩家对战)
- 市场采用 **V3 系统市场**(动态价格,与系统买卖,非玩家挂单)——更简单也更防作弊
- 商业化:内购(钻石:加速/稀有装饰),架构第一天预留
- 画面:2.5D 等距,先用免费素材(Kenney 等 CC0),支持后期换皮

- 94 建筑 × Level 1-3(282 条等级记录)、50 科技、30 NPC 原型 + 12 技能、26 市场资源、30 随机事件

## 3. 总体架构(与 v0.1 相同,补充执行细节)

```
浏览器 / PWA / (后期 Capacitor 壳)
        │
   前端 SPA(纯静态:HTML + JS + PixiJS 单文件引入)
   - 只展示预测值,不提交"获得多少资源",只提交意图(建造/研究/下单)
        │  HTTPS JSON API
        ▼
   PHP 8.3 纯 API(无框架,PDO 具名占位符,EMULATE_PREPARES=true)
   - 服务端权威结算;token 认证(localStorage,Capacitor 兼容)
        ▼
   MariaDB(utf8mb4,snake_case)
```

### 3.1 三个架构适配决策(2026-08-09 用户已确认)

V3 规格按常驻进程 Tick 设计,本项目跑在 cPanel 共享主机上,适配如下,**数值公式不变**:

1. **经济 Tick(规格建议 5 秒)→ 懒结算等价重放**:玩家请求到达时,用同一公式对 `deltaSeconds` 重放。
   经济公式是确定性的,结果与 5 秒 Tick 数学等价。前端面板约 10 秒轮询刷新。
2. **市场价格 Tick(规格建议 30 秒)→ cron(cPanel,每分钟)或首个请求懒补演化**:
   用存储的随机种子保证演化确定性;波动率按实际 Tick 间隔等比换算。
3. **随机事件(规格建议 60 秒检查)→ 仅玩家在线时触发**(状态轮询时检查),离线不出事件。
   对玩家公平,也免掉离线随机数重放的复杂度。

### 3.2 PostgreSQL → MariaDB 映射

- `JSONB` → `LONGTEXT` + `CHECK (JSON_VALID(col))`;`BIGSERIAL` → `BIGINT UNSIGNED AUTO_INCREMENT`
- `NUMERIC(p,s)` → `DECIMAL(p,s)`;`BOOLEAN` → `TINYINT(1)`
- 表结构分两层:**定义表(Seed,随版本部署)** 与 **玩家 Runtime 表(只能走迁移脚本)**,按 V3 第 1、12 节

## 4. V3 未覆盖、本项目补充的系统

### 4.1 土地购买(2026-08-09 用户已确认:花资源买地块)

- 地图划分为**地块**(每块 10×10 格)。开局免费解锁中心若干块,其余用资源+资金购买。
- 价格随已拥有地块数递增、并与时代挂钩(晚期时代地块用晚期资源定价);钻石可替代部分资源(可选加速)。
- 具体价格表在实现阶段给出初稿,标记为可调参数,与用户讨论后定。
- 对应 V3 平衡规则:「土地使用率 >85% 预警」,土地是各时代扩张瓶颈之一。

### 4.2 账号与认证

注册/登录(邮箱或用户名 + bcrypt),token(随机 64 hex,库存 hash),限流,CSRF 基线。

### 4.3 钻石(内购预留)

加速建造/升级/研究(V3 的 `duration`),购买稀有装饰;发放/消费全走 `diamond_log` 流水,第一天可审计。

### 4.4 互动

- **排行榜**:按时代 + 综合繁荣度(口径:人口+治理+国防加权,实现时定)分页。
- **参观好友城市**:只读拉取对方布局渲染。
- (玩家对玩家交易不做,市场按 V3 系统市场。)

### 4.5 PWA

manifest + service worker(静态资源缓存),后期 Capacitor 复用同一前端。

## 5. 分期计划(2026-08-09 用户已确认:首版 = 核心循环版)

数据一次性全部入库(10 时代 94 建筑 50 科技),功能系统分期:

1. **M1 核心循环版(先上 test)**:账号 + Seed 入库 + 建造/升级(事务+幂等)+ 生产懒结算 +
   粮食/人口/幸福/治理/物流 + 科技树 + 时代升级 + 土地购买 + 基础前端(等距地图、建造交互、综合面板)
2. **M2**:NPC 分配与技能加成 + 工具/道具
3. **M3**:系统市场(价格演化、手续费、成交量限制)+ 随机事件(权重/冷却/选项)
4. **M4**:排行榜 + 参观 + 每日任务/新手引导 + PWA + 钻石加速
5. **后期**:Capacitor 上架、支付接入、后台管理界面

依据 V3 第 0.1 节优先级:核心经济循环稳定之前不叠加波动系统。
